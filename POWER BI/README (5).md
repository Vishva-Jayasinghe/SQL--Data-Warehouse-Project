# 🚴 VeloEdge Sales & Customer Analytics Dashboard

## 🧠 Project Overview

This project presents an interactive **Power BI dashboard** for
analyzing sales and customer behavior of a bicycle and accessories
business (VeloEdge).

------------------------------------------------------------------------

## 🧹 Data Preparation (Python)

The dataset used in this project was **cleaned and transformed using
Python** before being loaded into Power BI.
